# Reference SNR-sweep result (`metrics_by_snr.csv`)

This table was produced with `scripts/render_sih_demo.py` (confidence-gated hybrid
inference: AI high-band branch + reference-assisted NLMS low-band branch, both blended
against the raw noisy signal based on the real-time-estimated current SNR -- see
`src/realtime/confidence_gate.py`), run against a checkpoint trained on this repo's
bundled real audio (`data/raw/speech_real/`, `data/raw/noise_real/`, plus real gunfire
and explosion clips added during interactive validation -- see `ATTRIBUTIONS.md`).

**Important provenance note:** this specific run happened interactively in the team's
Google Colab session (GPU training isn't possible in the environment that assembled this
repository), and the resulting checkpoint file itself is not bundled here (trained
checkpoints are large and environment-specific, not build artifacts). This CSV is kept as
a documented, dated reference point, not as a number regenerated by CI or verified by
whoever last edited this repo. **Do not treat it as a guarantee of what a fresh training
run will produce** -- the "Two ways to train" and "Real bundled audio" sections of the
main README explain how to regenerate this exact table (or a better one, with more data)
yourself:

```bash
python scripts/render_sih_demo.py \
  --checkpoint models/trained_real_v2/best.pt \
  --speech-csv data/processed_real/val_speech.csv data/processed_real/test_speech.csv \
  --noise-csv data/processed_real/noise.csv \
  --out results/sih_demo
```

## Reading the table honestly

- `Delta_SNR_dB` is real, positive improvement at low input SNR (up to +8.5dB at -10dB
  input) -- genuine noise cancellation in the hard case.
- `avg_alpha` shows the confidence gate working as designed: near 1.0 (trust the model)
  when input is very noisy, tapering to 0.05 (mostly leave it alone) as input SNR rises --
  so the flat/negative `Delta_SNR_dB` at high input SNR is *by design*, not a bug: the
  system is deliberately doing very little to signal that didn't need help.
- `Enhanced_STOI` clears the PS's 0.85 target at 10-15dB input SNR (0.867, 0.950) but not
  at low SNR -- report this as "meets the intelligibility target at moderate-to-high input
  SNR," not as a blanket claim.
- `Enhanced_PESQ` stays below the PS's 2.5 target across the whole sweep. This is the most
  honest open gap: PESQ penalizes any residual processing artifact heavily, and a model
  trained on ~450 pairs from 6 speakers will have audible artifacts. Closing this requires
  a much larger, more varied training set (see `DATASETS.md`), not further tuning of this
  checkpoint.
